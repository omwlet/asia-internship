## 🤝 How to Contribute

Found an internship that isn't listed? Add it! We accept contributions via **Pull Request** (preferred) or by opening an [issue](../../issues/new/choose) if you're not comfortable with git.

### Quick PR guide

1. **Check for duplicates** — search the table (Ctrl+F) for the company name first.
2. **Fork** this repository and edit `README.md`.
3. **Add one row** to the table using this exact format:

   ```markdown
   | Company Name | Role Title | 🇽🇽 City, Country *or* 🌐 Remote | 🟢 [Apply](https://direct-application-link) | YYYY-MM-DD |
   ```

4. **Rules for the row:**
   - Link must go to the **official application page** (no referral or tracking links).
   - Location must name a **specific Asian country** (with flag emoji if possible) or be marked 🌐 Remote. For remote roles, note any time-zone or region restriction.
   - `Date Posted` uses ISO format: `YYYY-MM-DD`.
   - Insert the row at the **top** of the table (newest first).
5. **Open a Pull Request** with the title: `Add: <Company> — <Role>`.

Full contributor rules live in [CONTRIBUTING.md](CONTRIBUTING.md).

### Reporting a dead link

If an application link is expired or broken, please [open a "Broken / Expired Link" issue](../../issues/new/choose) — or submit a PR marking the row 🔴 Closed.
